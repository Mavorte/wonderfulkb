- Pro supported canonical branches zdokumentovat success/failure/retry fragment a absence audit → unknown, cache reuse bez nového model call, signature disabled/returned failure, partial publish bez run terminal, lost/late/duplicate observations. Explicitně evidovat pokud stage skutečný producer vůbec nemá, nedoplnit business funkci kvůli zelenému testu.
- Ověřit build inclusion/import audit package ze skutečného worker a intake artifactů, deklarované env/IAM/resource potřeby pouze jako diff/checklist existujících owners bez credentials. Neplést dvě byte-shodné source files s provenance celého deployed image. Před deploymentem inspect/preserve existující konfiguraci, uchovat recovery artifact a použít revision/concurrency guards. Rutinní instalace a in-place deployment do existujícího AWS test cíle jsou podle AGENTS.md součást dodávky; žádné broad konfigurace/permissions nebo nový deployment framework.
- Host smoke runbook: přesné artifact/source digests k ověření; stávající supported synthetic upload/queue cesta, očekávané bezpečné event/HTTP assertions, limity nákladů a odstranění test fixture pouze podle skutečných supported operators. Pokud jeho skutečný runtime nemá podporované oprávnění, Jackie provede konkrétní operator krok v rámci stejného zadání; neobcházet denial a neuzavírat source-only jako hotové.
