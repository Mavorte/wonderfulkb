## Change
- Existující intake/FastAPI App Runner: `GET /v1/cases/{case_id}/processing/documents/{document_id}/runs`, `/runs/{run_id}`, a `/{document_id}/audit`. Reuse již existující route pokud je dodaná, ne duplikace serveru/proxy. Collection/snapshot čte jedno bounded evaluated document Query okno s limit1–100/next_token; run detail filtruje run z téhož okna, nevytváří celohistorické scan-until-found.
- Runs items jsou summaries POZOROVANÝCH runů v tomto okně, ne kompletní execution registr. Run detail a audit response výslovně obsahují observations/partial lifecycle a next_token/observed_at/coverage=partial; detail známého dokumentu bez run observations v aktuálním okně vrací unknown observation data s continuation, ne smyšlené 404 runu nebo nepravdivé empty-complete. Document/case existence a auth rozhoduje separátní trusted seam. Pokud existuje skutečný autoritativní run lookup, jeho neexistenci nesuplovat neúplným auditem.
- Exponovat pouze reducer allowlist a event evidence IDs/scope/outcomes; publikovaný result_status/reference odděleně od terminálního run statusu, partial publikace nemusí run ukončit. Nevyplňovat latest run/attempt nebo totals/percent z posledního času/sequence/neúplného okna. Při konfliktu unknown/ambiguous, bez heuristického business state machine.
- Cursor operation-bound: runs/run-detail/audit + case/document/run kde relevantní; last EVALUATED pozice, empty continuation legitimní; cross-operation/run token odmítnout. Žádné Scan, fanout přes další okna, nový index/projekce nebo mutable business analýza jako historie.
- Availability not_configured/not_instrumented/unknown jen dle doložených capability/reducer inputs; absence záznamu není not_instrumented. Nutný read source failure503, nikdy availability empty success. True case auth/scope404/403 a private,no-store včetně chyb, žádný shared-key→case claim trik. Signature/history config se nedoplňuje z dnešního prostředí.
- Zachovat attempts jako pozorované AttemptStarted a existující events/steps/pages. Cíleně sladit jediný YAML s partial window semantics, nepřevzít dřívější celohistorický/unavailable nebo unknown-run404 předpoklad bez autority. Bez content/artifact endpoints.
