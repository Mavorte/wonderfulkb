# Planning cache-reuse audit validation without manufacturing RED

When completing coverage for an audit event that already works, distinguish missing assertions from an actual behavior defect. A meaningful changed-payload duplicate check can prove immutable event-id semantics; if it passes before edits, record it as existing characterization rather than falsifying a RED. Separate direct validator rejection from a caller's fail-open handling, and characterize only a real public seam. A file-intake-only audit listener does not establish cache-producer behavior. Moto Decimal roundtrips and type-based read dispatch need explicit checks because DynamoDB returns Decimal and event types require explicit serializer and decoder allowlists.
