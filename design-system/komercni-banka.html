Barvy / Color

KB is mostly white, cool grey and near-black. Corporate red is reserved for the primary action, icons and accent links. The logo uses its own red, which differs slightly from the UI red.

Layout

Container max width 94rem (98rem on wide screens), 16px side padding on phones and 32px on desktop, 24-column grid. Main breakpoint is 992px; text blocks such as accordions span 14 columns with a 1-column offset.

Komponenty / Components

Re-created from the live page. They're a portable stylesheet, not KB's own code.

Button

Primary red for the single main action per view. Secondary is outlined dark, tertiary is a light fill used inside dark cards, quaternary is outlined white for dark surfaces. Pressing scales the button down. Every variant uses the same grey disabled style. Proposed: the 2px dark focus ring (kb.cz relies on the browser default).

Links

Inline links in body copy stay text-coloured and underlined. Action links in cards are red, medium weight, with a red chevron that slides 8px right on hover.

Form field

Inputs and selects are 48px tall with a 6px radius and a grey border that darkens on focus. In the error state the border and message turn red. The select uses a red chevron. Proposed: the focus ring and visible labels.

Tariff comparator

Four plans side by side on a white band. The recommended plan is lifted onto a dark slate card with a red badge, white title, mint check icons and a light tertiary button. Other plans use teal checks.
